# Previsão Brasileirão Série A

Escolha o mandante e o visitante e veja as probabilidades de vitória, empate e derrota, os gols esperados e os placares mais prováveis. A página também mostra as previsões dos próximos jogos e uma simulação do fim do campeonato.

As contas rodam no navegador, a partir dos parâmetros treinados (`params.json`). O modelo é a média de **Dixon-Coles** e **Elo**, treinado com jogos da Série A desde 2003.

Metodologia, backtest e código: [github.com/JulioBuzzi/brasileirao-ml](https://github.com/JulioBuzzi/brasileirao-ml)
